# E-commerce Investigative Data Analysis

## About the Project

This project explores the Brazilian Olist e-commerce dataset to understand how the marketplace performs across customers, orders, products, sellers, payments, reviews, and delivery activity.

The work starts by establishing the business context and understanding the structure of the available data. Nine related datasets are then loaded, checked, cleaned, and connected before moving into exploratory work and KPI measurement.

From that foundation, eight business questions are examined using the combined data. The final sections bring those results together into key findings, practical actions, and an executive summary.

## Dataset

The project uses the Brazilian Olist E-commerce dataset, covering different parts of the marketplace:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation
- Product Category Translation

Relationships between these tables are mapped through the data schema before integration.

## Project Workflow

**Business Understanding → Business Context → Investigation Goals → Datasets Used → Data Schema → Dataset Loading → Dataset Overview → Data Cleaning → Dataset Integration → EDA → KPI Overview → 8 Business Questions → Key Findings → Turning Insights into Action → Executive Summary**

## What Was Done

The datasets were first inspected individually to understand their size, columns, data types, missing values, duplicates, and overall structure.

Cleaning was carried out where required before the relevant tables were joined for further work. Exploratory analysis was then used to understand the combined data, followed by a KPI overview of the marketplace.

Eight business questions form the main analytical section of the project. Their results are brought together at the end to highlight the most important findings and translate them into actions that could support business decisions.
